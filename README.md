# مهندس دولة — الموقع الكامل

موقع للطلاب (بلا أي تسجيل) + لوحة أدمن لك وحدك على `/admin`.

## 1) النشر على Render
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (الملفات `index.html` و`server.js` في الجذر).
2. Render ← New ← **Web Service** ← اختر المستودع. Runtime: Node · Build Command: `echo no build` · Start Command: `node server.js` (أو Blueprint ليقرأ `render.yaml`).
3. أضف المتغيرات في Environment:

| المتغير | القيمة | ملاحظة |
|---|---|---|
| `GEMINI_API_KEYS` | `مفتاح1,مفتاح2,مفتاح3` | يتدرّج بينها، وعند تعطل مفتاح ينتقل للتالي |
| `ADMIN_PASSWORD` | كلمة سر قوية | بدونها لا تعمل لوحة الأدمن |
| `GITHUB_TOKEN` | توكن GitHub | لحفظ تعديلات الأدمن بشكل دائم (الخطوة 2) |
| `GITHUB_REPO` | `اسمك/اسم-المستودع` | |
| `GITHUB_BRANCH` | `main` | اختياري |
| `GITHUB_PREFIX` | مجلد الموقع داخل المستودع | اختياري، فقط إن لم يكن الموقع في الجذر |
| `GEMINI_MODELS` | `gemini-2.5-flash,gemini-2.5-pro` | اختياري: احتياط بين النماذج |
| `CHAT_LIMIT_PER_HOUR` | 40 | أسئلة لكل زائر في الساعة |
| `CHAT_DAILY_CAP` | 1500 | سقف يومي عام للأسئلة لحماية مفاتيحك |

## 2) توكن GitHub (للحفظ الدائم)
GitHub ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate:
اختر مستودع الموقع فقط، والصلاحية **Contents: Read and write**. انسخ التوكن إلى `GITHUB_TOKEN`.
**لماذا؟** تخزين Render المجاني يُمسح عند كل إعادة تشغيل، فتُحفَظ تعديلاتك في GitHub (دفعة واحدة بعد ~20 ثانية من آخر تعديل) ثم يعيد Render النشر وحده. تظهر التعديلات للطلاب فورًا، وتصير دائمة بعد الحفظ في GitHub. وهكذا يبقى لك سجل كامل ويمكنك التراجع.

## 3) لوحة الأدمن `/admin`
- **المواد:** إضافة وإعادة تسمية وترتيب وحذف.
- **الصور:** رفع عدة صور معًا (تُصغَّر تلقائيًا)، عنوان وتصنيف وفصل، إخفاء عن الطلاب، ترتيب ↑↓، حذف. يُقرأ نص كل صورة تلقائيًا بـ Gemini، ويمكنك تصحيحه بزر «النص».
- **الملفات:** رفع txt أو md أو pdf، أو كتابة ملف جديد وتعديل الملفات النصية.
- **التصنيفات:** أضف ما شئت (COURS وTD وTP وCORE…)، وتظهر للطلاب أزرار تصفية داخل كل مادة.
- أول مرة: زر «اقرأ نص الصور الناقصة» يقرأ كل صورك الحالية دفعة واحدة.

## 4) المعلم
يشرح بأسلوب مبسّط ومفصّل (فكرة، خطوات، مثال، تنبيه، اختبر نفسك) مع مفتاح «مبسّط جدًا / عادي». وعند الاستدلال بصورة يضع زرًا صغيرًا [صورة N] يفتح الصورة عند الضغط، وكذلك [درس N] للملفات النصية. الصور هي المصدر الأصلي والملفات النصية ثانوية.

## ملاحظات
- النسخة المجانية من Render تنام بعد خمول فيتأخر أول طلب نحو دقيقة.
- لا تشارك رابط `/admin` أو كلمة السر. بعد 6 محاولات خاطئة يُمنع الدخول 10 دقائق.
- `build.py` و`ocr.py` اختياريان لمن يفضل العمل على جهازه.
