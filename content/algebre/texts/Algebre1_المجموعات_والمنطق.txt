1. الروابط المنطقية (Les connecteurs logiques)
--------------------------------------------------------------------
*   ~ (النفي / Négation): عدم الانتماء.
*   ∧ (الاجتماع / Conjonction): "و" (و).
*   ∨ (الانفصال / Disjonction): "أو" (أو).
*   ⇒ (يستلزم / Implication): "إذا كان ... فإن ..."
*   ⇔ (يكافئ / Équivalence): "يتحقق إذا وفقط إذا كان" (يتكون من إذا وفقط إذا).

--------------------------------------------------------------------
2. المجموعات (Les Ensembles) - التعامل مع المجموعات
--------------------------------------------------------------------
- تعريف المجموعة: المجموعة في الرياضيات هي مجموعة من العناصر (أو الأشياء) التي تنتمي إلى نفس المجال.
- أمثلة: 
  A = {1, 2, 3} (مجموعة الأعداد)
  B = {السبت، الأحد، الاثنين، الثلاثاء، الأربعاء، الخميس، الجمعة} (أيام الأسبوع)
- المجموعات العددية:
  N: مجموعة الأعداد الطبيعية = {0, 1, 2, ...}
  Z: مجموعة الأعداد الصحيحة = {..., -2, -1, 0, 1, 2, ...}
  Q: مجموعة الأعداد الناطقة (الكسور) = {a/b | a, b ∈ Z, b ≠ 0}

- تساوي مجموعتين (Égalité de deux ensembles):
  لتكن A و B مجموعتين: A = B ⇔ A ⊂ B ∧ B ⊂ A
  (أي أن كل عنصر من A ينتمي إلى B، وكل عنصر من B ينتمي إلى A).

--------------------------------------------------------------------
3. العمليات على المجموعات (Opérations sur les ensembles)
--------------------------------------------------------------------
أ. التقاطع (Intersection - ∩):
   تقاطع A و B هو مجموعة العناصر المشتركة بينهما.
   A ∩ B = {x | x ∈ A ∧ x ∈ B}
   مثال: {1, 4, 6, 9} ∩ {4, 5, 6, 10} = {4, 6}

ب. الاتحاد (Union - ∪):
   اتحاد A و B هو مجموعة العناصر التي تنتمي إلى A أو تنتمي إلى B.
   A ∪ B = {x | x ∈ A ∨ x ∈ B}
   مثال: {1, 4, 6, 9} ∪ {4, 5, 6, 10} = {1, 4, 5, 6, 9, 10}

ج. الفرق (Différence - A - B):
   هو مجموعة العناصر التي تنتمي إلى A ولا تنتمي إلى B.
   A - B = {x | x ∈ A ∧ x ∉ B}
   مثال: {1, 4, 6, 9} - {4, 5, 6, 10} = {1, 9}

د. الفرق المتماثل (Différence symétrique - A Δ B):
   A Δ B = (A - B) ∪ (B - A)
   مثال: {1, 4, 6, 9} Δ {4, 5, 6, 10} = {1, 5, 9, 10}

هـ. المتممة (Complémentaire - C_E(A)):
   لتكن E مجموعة شاملة و A مجموعة جزئية منها. متممة A بالنسبة إلى E هي العناصر التي تنتمي لـ E ولا تنتمي لـ A.
   C_E(A) = {x ∈ E | x ∉ A} = E - A
   أمثلة: إذا كانت E = {2, 3, 4} و A = {3}، فإن C_E(A) = {2, 4}.
   مثال في N: C_N(E) = N - {1, 2, 3, 4, 5} = {0, 6, 7, ...}
   مثال في R: C_R(F) = R - {2, 4, 6} (تكتب على شكل مجالات).

و. مجموعة الأجزاء (Ensemble des parties - P(E)):
   تعريف: لتكن E مجموعة. نسمي مجموعة أجزاء E، مجموعة كل المجموعات الجزئية لـ E.
   P(E) = {A | A ⊂ E}
   أمثلة: إذا كانت E = {1}، فإن P(E) = {∅, {1}}. وعدد العناصر |P(E)| = 2.
   إذا كانت E = {1, 2}، فإن P(E) = {∅, {1}, {2}, {1, 2}}. وعدد العناصر |P(E)| = 4.
   * ملاحظة هامة: إذا كان |E| = n، فإن |P(E)| = 2^n

ز. تجزيء مجموعة (Partition d'un ensemble):
   لتكن E مجموعة غير خالية. و لتكن A_1, A_2, ..., A_n مجموعات جزئية من E.
   نقول أن المجموعة {A_1, A_2, ..., A_n} تشكل تجزيئاً لـ E إذا تحققت الشروط التالية:
   1. A_i ≠ ∅ (جميع المجموعات غير خالية).
   2. A_1 ∪ A_2 ∪ ... ∪ A_n = E (اتحادها يساوي E).
   3. A_i ∩ A_j = ∅ لكل i ≠ j (ليس بينها أي عنصر مشترك، أي مثنى مثنى متقاطعتان بفراغ).
   * مثال: E = {1, 2, 3, 4, 5, 6, 7, 8, 9}
     A_1 = {1, 5, 10} (خطأ مطبعي في الدفتر، يفترض ألا يتجاوز عناصر E)، A_2 = {2, 4, 6}، A_3 = {3, 7, 9}.
     المجموعة {A_1, A_2, A_3} تشكل تجزيئاً لـ E.
   * مثال آخر (ليس تجزيئاً): E = {1, 2, 3, 4, 5}، A_1={1, 2}، A_2={3, 4}، A_3={4, 5}. (لأن هناك عنصر مشترك بين A_2 و A_3).

--------------------------------------------------------------------
4. الجداء الديكارتي (Produit cartésien)
--------------------------------------------------------------------
لتكن E و F مجموعتين غير خاليتين. نسمي الجداء الديكارتي للمجموعتين E و F:
E × F = {(x, y) | x ∈ E ∧ y ∈ F}
أمثلة: 
E = {1, 2, 4} و F = {6, 7}
E × F = {(1,6), (1,7), (2,6), (2,7), (4,6), (4,7)}
F × E = {(6,1), (6,2), (6,4), (7,1), (7,2), (7,4)}
* ملاحظة: |E × F| = |E| × |F| (عدد عناصر الجداء هو ضرب عدد عناصر المجموعتين).

--------------------------------------------------------------------
5. تطبيقات وقوانين المنطق (من خلال البراهين)
--------------------------------------------------------------------
* مثال تطبيقي من السبورة:
  E = {1, 2, 3, 4, 5, 6}، F = {2, 4, 6}
  E ∩ F = {2, 4, 6}
  E ∪ F = {1, 2, 3, 4, 5, 6}
  E - F = {1, 3, 5}
  F - E = ∅
  E Δ F = {1, 3, 5}

* البراهين باستخدام خواص المجموعات (قوانين دي مورغان وغيرها):
  1. إثبات أن A = B إذا كان (A ∪ B = A ∩ B):
     - نعلم أن: A ⊂ (A ∪ B) (لأن الاتحاد يحتوي الكل).
     - وبما أن المعطى (A ∪ B = A ∩ B)، إذن A ⊂ (A ∩ B).
     - ونعلم أن (A ∩ B) ⊂ A. إذن نستنتج أن A = (A ∩ B).
     - بالمثل بالنسبة لـ B. ومنه نستنتج A = B.

  2. إثبات أن (A ∪ B = A ∪ C) ∧ (A ∩ B = A ∩ C) ⇒ B ⊂ C:
     - نأخذ عنصر x ∈ B. لدينا حالتان:
       الحالة 1 (x ∈ A): إذن x ∈ (A ∩ B). وبما أن (A ∩ B = A ∩ C)، فإن x ∈ (A ∩ C) ومنه x ∈ C.
       الحالة 2 (x ∉ A): بما أن x ∈ B، فإن x ∈ (A ∪ B). وبما أن (A ∪ B = A ∪ C)، فإن x ∈ (A ∪ C). وبما أن x ∉ A، إذن وجب أن x ∈ C.
     - في كلتا الحالتين، إذا كان x ∈ B فإن x ∈ C. ومنه نستنتج B ⊂ C.

  3. متممة المتممة (C_E(C_E(A)) = A):
     - x ∈ (C_E A) ⇔ x ∉ (C_E A) ⇔ x ∈ A.

  4. متممة الاتحاد (C_E(A ∪ B) = C_E(A) ∩ C_E(B)) [قانون دي مورغان]:
     - x ∈ C_E(A ∪ B) ⇔ x ∉ (A ∪ B) ⇔ x ∉ A ∧ x ∉ B ⇔ x ∈ C_E(A) ∧ x ∈ C_E(B) ⇔ x ∈ (C_E(A) ∩ C_E(B)).

  5. متممة التقاطع (C_E(A ∩ B) = C_E(A) ∪ C_E(B)):
     - x ∈ C_E(A ∩ B) ⇔ x ∉ (A ∩ B) ⇔ x ∉ A ∨ x ∉ B ⇔ x ∈ C_E(A) ∨ x ∈ C_E(B) ⇔ x ∈ (C_E(A) ∪ C_E(B)).

  6. قانون التوزيع (A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)):
     - x ∈ A ∪ (B ∩ C) ⇔ x ∈ A ∨ (x ∈ B ∧ x ∈ C)
     ⇔ (x ∈ A ∨ x ∈ B) ∧ (x ∈ A ∨ x ∈ C) 
     ⇔ x ∈ (A ∪ B) ∧ x ∈ (A ∪ C) 
     ⇔ x ∈ (A ∪ B) ∩ (A ∪ C).

  7. التكافؤات الهامة (إذا كان A ⊂ B):
     A ⊂ B ⇔ (A ∪ B = B) ⇔ (A ∩ B = A) ⇔ (C_E(A) ∪ B = E) ⇔ (A ∩ C_E(B) = ∅).
     - البرهان: (A ⊂ B ⇒ A ∪ B = B)
       نعلم أن A ⊂ B، إذن B ∪ B = B.
       نعلم أن A ∪ B ⊂ B ∪ B (بما أن A ⊂ B).
       ومنه A ∪ B ⊂ B. وبما أن B ⊂ A ∪ B دائماً، إذن A ∪ B = B.
